## Implementation Details

### New Features Added (16D total)

#### 1. Temporal Statistics Enhancement (6D)
**Location:** `src/spinlock/features/temporal/temporal.py` → `_extract_local_temporal()`

- **Temporal Skewness** (3D - per channel)
  - Measures asymmetry in temporal evolution
  - Formula: `E[(X - μ)³] / σ³`
  - Captures non-Gaussian behavior patterns

- **Temporal Kurtosis** (3D - per channel)
  - Measures tail behavior and outlier presence
  - Formula: `E[(X - μ)⁴] / σ⁴`
  - Detects heavy-tailed distributions

**Computational Cost:** Reuses existing mean/std computations (1× variance cost)

#### 2. Multi-Lag Autocorrelation (5D)
**Location:** `src/spinlock/features/temporal/temporal.py` → `_extract_local_temporal()`

- **Lag-2, Lag-5, Lag-10, Lag-20 autocorrelations** (4D)
  - Captures temporal memory at multiple scales
  - Each returns global average across channels

- **Mean Multi-Lag Autocorrelation** (1D)
  - Average of all computed lags (1, 2, 5, 10, 20)
  - Provides overall temporal correlation measure

**Computational Cost:** 5× autocorrelation computation (~2× existing cost)

**Implementation Details:**
- Modified `_compute_autocorr()` to accept `lag` parameter
- Graceful degradation when window too small for lag

#### 3. Sample Entropy Proxy (1D)
**Location:** `src/spinlock/features/temporal/temporal.py` → `_extract_local_stability()`

- Measures regularity/predictability of temporal evolution
- **Proxy Implementation:** Standard deviation of consecutive differences
- Complements Lyapunov exponent with regularity metric

**Computational Cost:** 1 std computation (~0.5× variance cost)

#### 4. Energy Metrics Enhancement (2D)
**Location:** `src/spinlock/features/temporal/temporal.py` → `_extract_instantaneous()`

- **Enstrophy** (1D - global)
  - Vorticity proxy: mean of squared spatial gradients
  - Physics-informed turbulence indicator
  - Formula: `mean(u_x² + u_y²)` across channels

- **Divergence Proxy** (1D - global)
  - Measures field expansion/contraction
  - Formula: `mean(|u_x| + |u_y|)` across channels
  - Detects compression/rarefaction patterns

**Computational Cost:** 0× (reuses existing gradient computations)

#### 5. Spectral Entropy (1D)
**Location:** `src/spinlock/features/temporal/spectral.py` → `extract()`

- Shannon entropy of normalized power spectral density
- Measures spectral complexity: high = noise-like, low = tonal
- Complements spectral flatness with information-theoretic perspective
- Formula: `H = -Σ p(f) * log(p(f))`

**Computational Cost:** 0.1× (just log and sum over existing PSD)

## Code Quality

### Adherence to Best Practices

✅ **DRY (Don't Repeat Yourself)**
- Reuses existing computations (gradients, mean, std)
- Shared `_compute_autocorr()` helper for all lags
- No redundant calculations

✅ **GPU-First & Vectorized**
- All operations use PyTorch tensor ops
- No loops over batch/channel dimensions
- Broadcasting used where possible

✅ **Numerical Stability**
- Added `eps = 1e-8` to all division operations
- Graceful handling of zero/constant inputs
- No operations that can produce NaN/Inf

✅ **Defensive Programming**
- Window size checks before computation
- Fallback to zeros when insufficient history
- Proper shape preservation throughout pipeline

## Computational Cost Analysis

| Feature | Complexity | GPU-Friendly | Relative Cost |
|---------|------------|--------------|---------------|
| Skewness/kurtosis | O(T×C) | ✅ Yes | 1× (same as variance) |
| Multi-lag autocorr | O(T×L) | ✅ Yes | 2× (5 lags) |
| Sample entropy | O(T) | ✅ Yes | 0.5× (std computation) |
| Enstrophy | O(H×W) | ✅ Yes | 0× (reuse gradients) |
| Divergence | O(H×W) | ✅ Yes | 0× (reuse gradients) |
| Spectral entropy | O(F) | ✅ Yes | 0.1× (log/sum) |
| **Total Overhead** | - | - | **~4%** |

Where:
- T = temporal window (5-50)
- C = channels (3)
- L = number of lags (5)
- F = FFT bins (~100)
- H×W = spatial dimensions (64×64)

**Estimated Runtime Impact:** <5% increase in feature extraction time
