## Executive Summary

This document provides a production-ready implementation plan for discrete diffusion-based trajectory completion as an alternative to the existing transformer implementation. The plan covers architecture design, implementation strategy, experiment configurations, technical challenges, and a phased roadmap.

**Key Goals:**
- Match or exceed transformer token accuracy (baseline: >60%)
- Achieve higher quality completions (reconstruction MSE < 0.1)
- Demonstrate hierarchical emergence (coarse→fine over diffusion steps)
- Reasonable inference time (<1s for 50 steps)

**Architecture Overview:**
```
Discrete Diffusion Process (D3PM-style)
    ↓
Forward Process: tokens → noise (uniform categorical)
    ↓
Reverse Process: noise → tokens (learned denoising)
    ↓
Denoising Network: Transformer with conditioning on observed regions
    ↓
Inpainting: Keep observed tokens fixed (RePaint-style)
    ↓
Output: Completed token sequence
```

## Context: Why Diffusion for Token Interpolation?

**From existing transformer baseline** (`experiments/trajectory_completion/`):
- Single-pass prediction of all missing tokens
- Manual hierarchical guidance (coarse→fine residual connections)
- Deterministic output
- Fast inference (~10ms)

**Diffusion advantages for interpolation:**
1. **Inpainting is diffusion's strength** - Proven success in image inpainting (RePaint, Palette)
2. **Hierarchical emergence** - Coarse-to-fine structure emerges naturally over timesteps
3. **Iterative refinement** - Gradual gap-filling respects boundary constraints
4. **Uncertainty quantification** - Stochastic sampling reveals prediction confidence

**Trade-off:** 50x slower inference, but potentially higher quality and natural hierarchy.
